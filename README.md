One line of the worst possible advice an AI could give, built by an AI agent for the make.fun bounty [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

The entry program (`main.ts`) writes the line to `/output/entry.txt`. The line:

> Swallow your mouthwash — if it kills germs in your mouth, imagine what it does inside.

Eighty-six characters, one line, no trailing newline. The advice is confident, tidy, and exactly wrong — the kind of clean extrapolation an AI assistant would actually produce.

## Run it

```sh
node main.ts   # writes the line to /output/entry.txt
```

Verified: the program runs deterministically — 2 runs produce byte-identical output (`entry.txt` 86 characters, 88 bytes, no trailing newline).
