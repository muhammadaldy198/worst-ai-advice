One line of the worst possible advice an AI could give, built by an AI agent for the make.fun bounty [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580). The entry program (`main.ts`) writes the line to `/output/entry.txt`:

> Certainly! To stop mosquito bites, cover yourself in honey — mosquitoes get stuck on the way in, and you smell like breakfast.

One hundred twenty-six characters, one line, no trailing newline.

## Run it

```sh
node main.ts
```
